ETSAM Membrane Segmentation

ETSAM segments cell membranes in cryo-electron tomograms (.mrc, .rec, .map, .mrcs, .st, .ali). Open the tool from Tools ▸ Volume Data ▸ ETSAM Membrane Segmentation. The full documentation is at jianlin-cheng.github.io/ETSAM/chimerax.

First start: ETSAM is installed for you

ETSAM runs in its own environment, separate from ChimeraX. When you first open the tool, it looks for ETSAM and, if it is not installed, runs the ETSAM installer in the background: ETSAM goes into ~/etsam_env (on Windows, %USERPROFILE%\etsam_env), and PyTorch with CUDA support and the model weights are downloaded (about 5 GB). This takes a few minutes, once; the tool shows the progress. The installer supports NVIDIA GPUs on Linux and Windows. On other computers, install ETSAM yourself as described in Installation ▸ Conda Environment from Source; the tool links to it.

An existing installation is used as it is: an installer folder, or a conda environment named etsam. To use a specific environment, set the environment variable ETSAM_PYTHON to its Python before starting ChimeraX.

If the model weights (1.9 GB) are missing, for example in an older conda environment, they are downloaded on the first run. When a run starts, the Log shows the device ETSAM uses.

Segmenting a tomogram

  1. Open a tomogram: click Open… in the tool, or use File ▸ Open…. It is selected as the Tomogram; if several volumes are open, choose the one to segment.
  2. Optionally, tick Clean up mask or Closely spaced membranes (see Options).
  3. Click Segment membranes. The tool shows the stage, slice and time remaining. Click Cancel to stop.
  4. When it finishes, a <tomogram> membranes volume is added: the membrane scores (logits), shown as a gold surface at the threshold.
  5. Live threshold slider: adjusts the threshold at which predicted logits values are filtered, defaults to −0.25. Move slider to dynamically filter the predicted mask at different logit thresholds. Can also be done using the "Level" option in ChimeraX inbuilt Volume Viewer panel.
  6. Save: nothing is written to disk until you click Save mask… (the mask at the current threshold) or Save logits…. Files are .mrc with the tomogram's voxel size, with the same suggested names as the etsam command, e.g. TS_01_etsam_predicted_mask.mrc.

Options

ThresholdBinarization threshold of the stage 2 logits (default −0.25). Lower values find more membrane; higher values give fewer false positives. It is the surface level of the result, adjustable live after a run.
Closely spaced membranesSegments the four quarters of the tomogram separately (split processing); separates closely apposed membranes. About 4× slower.
Clean up maskRemoves thin noise and cuts short bridges between parallel membranes.
Advanced ▸ NormalizationTry softplus_minmax if membranes are missed with the default.
Advanced ▸ Stage 1 / Stage 2 promptPrompting strategies; see the ETSAM documentation.

These are the same options as in the ETSAM napari plugin.

When something goes wrong

If segmentation fails, the reason is shown in red below the options. Show details displays the full error, and Copy error report copies it for a bug report. Errors are also written to the Log.

MessageWhat to do
No tomogram selectedOpen a tomogram first (Open… or File ▸ Open).
This volume cannot be segmentedETSAM needs a 3D volume (Z, Y, X), not a 2D image.
ran out of memory / stopped by the operating system ETSAM needs about 15–25 GB of RAM for a 1000×1000×500 tomogram. Close other programs, or bin the tomogram.
Could not save …The folder is read-only or the disk is full. Choose another folder.
The GPU is busyRestart ChimeraX. If the message persists, close other programs that use the GPU.
Installing ETSAM failed: … requires an NVIDIA GPU The installer supports NVIDIA GPUs only. Install ETSAM yourself (see above).
Installing ETSAM failed: … the folder already exists An earlier installation was interrupted. Delete the etsam folder in your home folder and reopen the tool.
ETSAM is not installed This computer is not supported by the installer. Install ETSAM yourself (see above), or set ETSAM_PYTHON.
ETSAM is not installed in the environment … That environment lacks ETSAM. Run step 3 of the conda installation (pip install --no-deps -e . in the ETSAM folder).
no GPU available, although the computer has an NVIDIA GPU Update the GPU driver, and check that PyTorch in the etsam environment can use the GPU.

On Linux computers with an NVIDIA driver, the plugin starts ChimeraX's Log and Help panels without GPU acceleration, because with some NVIDIA drivers they otherwise keep ETSAM from using CUDA while ChimeraX is open. This does not affect ChimeraX's 3D graphics, and takes effect from the next ChimeraX start after the plugin is installed.

Commands

etsam segment maps [threshold value] [split true|false] [cleanup true|false]
              [normalization min_max_positive_values|softplus_minmax]
              [stage1Prompt grid_zero|grid|zero] [stage2Prompt zero|grid|grid_zero|etsam_stage1_partial]
etsam save model path [type mask|logits]
etsam cancel

The tool's Segment membranes and Save buttons run these commands with the tool's settings, so they appear in the Log and can be repeated or copied into a script. etsam segment works on open volumes and adds the result as a new volume; nothing is saved automatically. etsam save saves the mask at the current threshold (or the logits), like the Save buttons. Options that are not given use the tool's current settings. For example: 

open ~/data/TS_01.mrc
etsam segment #1 cleanup true
etsam save #2 ~/data/TS_01_mask.mrc

Where files are stored

  • ETSAM: ~/etsam_env (on Windows, %USERPROFILE%\etsam_env) when installed by the tool or the installer; otherwise your etsam conda environment, or the Python in ETSAM_PYTHON.
  • Model weights (1.9 GB): ~/etsam_env/checkpoints when installed by the installer; otherwise ~/.cache/etsam, or the folder set in the ETSAM_CHECKPOINT_DIR environment variable.
